each components used in the form are

1. label : Used to provide a description for an input element

2. input : Used to create an input field where users can enter data

3. form : Used to create an HTML form for user input

4. button : Used to create a clickable button

5. br : Used to create a line break

6. for : Used to associate a label with an input element

7. placeholder : Used to provide a hint to the user about what to enter in the input field

8.id: The id attribute is used to uniquely identify an element in the HTML document.

9.type: The type attribute is used to specify the type of input element.

10.name: The name attribute is used to specify the name of an input element.

11. value: The value attribute is used to specify the value of an input element.

12. required: The required attribute is used to specify that an input element must be filled out before submitting the form.
